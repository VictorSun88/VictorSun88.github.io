生活中的概率分布

发表于 2025-12-13 更新于 2026-02-02 分类于 自然科学
本文字数： 2.3k 阅读时长 ≈ 2 分钟

从数学上看，有很多种类的概率分布，总体根据分布形状可以分为两大类：轻尾分布与拖尾分布。所谓轻尾分布，指的是概率分布相对集中，当取值过大或过小时，概率迅速趋近于0；而拖尾分布刚好相反，概率分布相对不集中，即使数值很大以后，还是有一定的概率出现，其分布曲线呈现出一个长长的尾巴。在生活中有三种常见的概率分布，分别是正态分布（高斯分布）、对数正态分布和幂律分布。

正态分布

正态分布是生活中最常见的分布之一，因此称之为“正态”即“正常的状态”。它的分布形状是一个钟形曲线，有明确定义(well-defined)的平均值和标准差(涨落)，并且概率分布集中于平均值的两侧，在边缘处概率值迅速减小至0，是最容易预测的一种分布。

正态分布有$ -sharp $ 的特点，即正态分布量的绝对涨落 ΔX 随着 $\sqrt{N}$ 的增大而增大，但相对涨落ΔX/X却随着$\sqrt{N}$ 增大而减小。

中心极限定理：当一个事件的期望同时受到很多随机因素影响，并且这些随机因素之间通过叠加效应共同影响结果时，这时期望值呈现出来的分布就是正态分布。

对数正态分布

神奇的对数

苏格兰数学家约翰·纳皮尔（John Napier）于1614年发表《奇妙对数表》，为解决大数乘除运算的繁琐而引入对数。它是一个深植于自然中的底层代码，它无处不在，于自然数值紧密地联系在一起。

对数最重要的功能就在于它可以把乘除运算变成加减，原数的非线性运算通过取对数的方式就转化为了线性的运算：

\[ \log N_1 N_2 N_3 = \log N_1 + \log N_2 + \log N_3
\]

\[ k\cdot \log N = \log N^k
\]

由此我们发现，对一个数值取对数，就可以得到其数量级大小。原本跨越几个数量级的数字，通过对数运算就可以将其“展平”，变成大小相近的数字。

通过微分运算可以发现，对数的变化量就是原数的相对变化量：

\[ d(\log N)=\frac{dN}{N} \]

这展现了一个数字的增长速度与数量级变化之间的关系，如果一个数字N是线性增大的，那么其数量级的变化随着数值的增加却越来越小。

它揭示了对数在自然变化中的强大之处，对数的增大不是一个线性增加的过程（永远以一个恒定的速率增长），而是取决于当前所处的状态。当一个数字足够大时，它需要更大的变化量才能使其对数也呈现出可观的变化。这与人类感官的感受是对应的，例如我们对光、声、震动的感知近似对数响应（如光强、分贝、里氏震级等）。

对数坐标

对数坐标的定义基于对数的数学性质：坐标轴上的距离与数值的对数成正比，即等间隔对应等比例变化（如每增加一个单位刻度，数值乘以固定倍数）。坐标轴刻度值与原点的距离正比于该刻度的对数：

\[ d \propto lg(x) \]

许多自然现象（如感官感知、物理定律）本质是比例关系而非绝对差，对数坐标能更自然地反映这种特性。当数据跨越多个数量级时，线性坐标难以同时清晰展示极小值和极大值，而对数坐标可以压缩大值尺度、扩展小值尺度，使所有数据点均匀分布，避免图形被极端值主导。

对数正态分布

当一个事件的期望受到多个随机因素影响，并且这些影响因素之间不是互相独立的，它们体现在期望值上是相乘的关系时，这时给期望值取一个对数，就能把相乘的因子变成相加的项，因此在取对数之后呈现出正态分布，这种分布我们称之为对数正态分布。

\[ E = X_1 X_2 X_3 \]

\[ \log E = \log X_1 + \log X_2 + \log X_3 + \cdots
\]

对数正态分布也有固定的期望值和标准差，但不同于正态分布集中的概率分布，对数正态分布会有一个很长的“拖尾”，这就导致其出现极端事件的可能性要远大于正态分布。

幂律分布

幂律分布也是广泛存在于生活中的分布，但不同于上面两种分布，它没有固定的期望值和标准差，出现极端事件的可能性要比以上两种分布大得多，因此是最难预测的一种分布。

当一个期望值包含两个指数关系时，其中一个指数衰减，另一个指数递增，这两个因素综合，就会形成幂律分布。
