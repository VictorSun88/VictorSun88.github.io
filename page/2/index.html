量子纠缠

最近读了不少量子纠缠相关的文献，对其有了一点模糊的理解。

我总是试图把抽象的概念具象化，喜欢通过现实模型的类比来理解物理规律。

“纠缠”是一个典型的量子概念，经典中也有类似的概念，称为“关联”。

在我看来，纠缠的概念并不难理解。之前人们把它描述为“超距作用”，即纠缠粒子之间的作用可以无视距离的限制，这确实令人费解。

但我认为，这种理解方式是不正确的。纠缠并不是实时的相互作用，而是早在观察到现象之前就已经确定的状态。换言之，我认为所谓的“超距作用”不过是人类的错觉，之所以会出现奇怪的现象是因为实验操作使得我们只看到那一部分的粒子。

本文字数： 2.3k 阅读时长 ≈ 2 分钟

从数学上看，有很多种类的概率分布，总体根据分布形状可以分为两大类：轻尾分布与拖尾分布。所谓轻尾分布，指的是概率分布相对集中，当取值过大或过小时，概率迅速趋近于0；而拖尾分布刚好相反，概率分布相对不集中，即使数值很大以后，还是有一定的概率出现，其分布曲线呈现出一个长长的尾巴。在生活中有三种常见的概率分布，分别是正态分布（高斯分布）、对数正态分布和幂律分布。

人格类型

发表于 2025-12-11 更新于 2026-03-14 分类于 心理生理
本文字数： 5.4k 阅读时长 ≈ 5 分钟

人格有多个层次，心理学上大致可分为「生理人格」「社会人格」和「意志人格」三方面，对应我们天生的模式，被社会化后的表现，以及理想中的自己，三者之间互相作用，共同形成了完整的人格。

人格类型分类有两个最广为流传的理论——十二星座（占星学）和MBTI（荣格八维）。它们分别建立于不同的理论基础，在巴纳姆效应等心理学作用的影响下，普遍被大众所接受。

巴纳姆效应（Barnum effect），也称福勒效应（Forer effect）、星相效应（Astrological effect），是描述心理学上的一种认知错误，即人们常常认为一种笼统的,一般性的人格描述十分准确地揭示了自己的特点，即使这种描述十分笼统、空洞，仍然认为反映了自己的人格面貌。是一种典型的认知偏差行为。这种效应可以部分解释一些超自然信仰和实践的广泛接受，例如占星术、算命、气场解读和某些类型的性格测试

游戏启发的问题

有一款游戏，名为《祖宗模拟器》，游戏主要内容就是从祖宗开始，成家立业、生儿育女，通过不断置办田产、培养子女、投资商业、步入仕途等方式，实现家族的兴盛和持续繁荣。但当一个家族首领逝世后，就要选择一个继承人，然后将家族产业持续运营下去。

沉浸式地游玩了一段时间之后，我发现了几点有趣的现象： 1. 个人的成功可以助力家族的兴盛，但是如果家族里只有少数几个人能力很强的话，那么当时表面上看起来很厉害，但却会因为人数的限制而很难持久繁荣下去； 2. 家族的规模似乎对于整体的繁荣至关重要，尽管家族里没有非常伟大的人物，只要规模足够庞大，完全可以支撑家族的发展，并且有利于代际间的传承； 3. 如果想要培养一个非常有能力的人物，似乎越是繁荣的家族成功的概率越大。小家族的婚姻以及活动范围只局限于一个很小的地方，不利于家族子女的培养。 4. 对于某个杰出的人才，他一开始越是优秀，珍贵的资源就越是流向他，他成长的速度也越快，使得其能够在官场上平步青云。
